# 地图工作台 V2 路线

## 产品方向

V2 将当前多个标签页收敛为一个以地图为中心的工作台：

- “地图掉落总览”作为默认主界面，支持艾欧泽亚总览、大区下钻和返回。
- “职业查找地图”收进右侧职业栏，不再保留大表格作为主界面。
- 职业、宠物、武器、掉落地区和完成状态由地图右侧的滑出抽屉承载。
- 页面以地图占满整个视口，地区层级与职业信息由两侧栏承载。
- “地图查找职业”不进入 V2 主流程；其中额外武器数据暂时保留在旧版本中，待 V2 稳定后再决定是否归档。

## 阶段与提交边界

0. 保存当前可运行地图原型，形成可回退基线。
1. 将职业、地区、地图配置和进度状态拆成统一的类型化数据层，并增加数据完整性测试。
2. 建立 Vite、Vue 3 和 TypeScript 新界面框架，完成应用外壳和设计变量。
3. 实现地图工作台、艾欧泽亚总览和大区下钻。
4. 实现职业详情、地区详情侧栏以及全局完成状态同步。
5. 实现移动端底部抽屉、触摸布局与响应式交互。
6. 完成旧进度迁移、自动化测试、性能优化、可访问性与发布说明。

每完成一个阶段并通过相应验证后单独提交。

## 交付状态

0～6 阶段已按顺序完成。当前实现已经收敛为单一地图工作台，旧版大表格不再进入主流程；数据完整性、旧进度迁移、侧栏交互、生产构建和桌面/手机布局均纳入验收。

完成 0～6 阶段后又进行了一轮极简化迭代：移除独立页头、介绍区、卡片式工作台和页脚，让地图直接占满视口；原桌面侧栏与移动端底部抽屉统一为右侧滑出抽屉。

后续导航迭代将职责拆分为可收起的左右两侧：左侧地图栏只保留艾欧泽亚总览和八个大区两级导航，右侧职业栏根据当前地图显示职业列表，并允许从职业详情返回列表。

完成首轮稳定性重构：侧栏尺寸变化后地图会重新适配可用视口，地图气泡按完整宽高约束在视口内；移除已废弃的职业筛选链路和重复地区关系，将职业详情、奖励预览、地图标记表现及样式拆成可独立测试的模块，并补齐弹窗焦点、存储失败、剪贴板回退和工作台互斥状态测试。

## V2 首版范围

必须包含：

- 艾欧泽亚总览及八张大区地图。
- 地图下钻、返回和相关区域高亮。
- 职业与地区详情侧栏。
- 职业完成状态切换与本地持久化。
- 旧版职业完成状态迁移。
- 桌面端详情栏进入三栏布局并为地图预留空间，移动端使用互斥的地区与职业模态弹窗。
- 古武、魂武、义武素材的地图标记、类型图例和区域详情。
- 所有地图气泡使用一致的地点名称区，并用独立信息区展示职业和武器素材掉落。
- 左右侧栏提供独立详细模式，分别展开地区掉落摘要与职业奖励预览入口。
- 独立宏弹窗提供宠物召唤与武器检索命令的分类列表和一键复制。

暂不包含：

- 用户账号和云同步。
- 路线规划。
- 地图标注编辑器。
- 多主题和复杂动画。

## 数据与素材约束

- 职业、武器素材、地区和地图坐标只保留一份基础数据，反向关系全部派生。
- V2 的完成状态只以职业为单位，旧版地区勾选不会迁移到新的完成状态中。
- 地图以九张 1024×1024 JPEG 在本地缓存，缩放交给 Leaflet 完成。
- 地图底图与子地区纹理由本机游戏客户端提取，并在构建素材时把高亮烘焙到成品图。
- 页面保留 Leaflet 与地图素材权利方的来源说明。
