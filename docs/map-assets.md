# 地图素材说明

项目发布九张本地地图，页面运行时不会请求第三方地图接口或素材服务器。

- 来源：本机《最终幻想 XIV》游戏客户端的 `ui/map` 与 `ui/icon` 资源
- 提取工具：`scripts/extract-ffxiv-maps.ps1`
- 收录地图：艾欧泽亚世界图，以及拉诺西亚、黑衣森林、萨纳兰、库尔札斯、阿巴拉提亚、龙堡、基拉巴尼亚、奥萨德
- 发布精度：1024×1024
- 文件数量：9 个 JPEG 文件
- 八张地区图已烘焙 50 个有效子地区纹理，并保留原有的轻微浅金色边缘光晕
- 页面运行时只加载当前地图的单张 JPEG，缩放由 Leaflet 在浏览器内完成

旧版地图切片与质量对比页已经从仓库删除，不参与开发或生产构建。原始底图、高亮纹理和中间合成结果保留在被 Git 忽略的 `source-assets/maps` 目录，便于在本机重新生成发布素材。

地图组件通过 npm 使用 Leaflet 1.9.4。Leaflet 的 BSD 2-Clause 许可证全文保存在 `public/THIRD_PARTY_NOTICES.txt`，并随生产构建发布。
