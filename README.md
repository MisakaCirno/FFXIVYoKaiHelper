# FFXIVYoKaiHelper

FF14 妖怪手表联动的地图优先收集工具。玩家可以从艾欧泽亚总览下钻到八个大区，直接查看每张地图涉及的职业，并在地图或详情侧栏同步记录完成状态。

## 主要能力

- 艾欧泽亚总览与八个大区的本地地图，不依赖运行时第三方地图接口。
- 展示古武 12 种魂晶、魂武 6 种水晶和义武 5 种记忆晶块的区域掉落，并复用项目内已有素材图标。
- 地图气泡拆成统一的地点名称区和独立信息区，职业及古武、魂武、义武信息与地点名称保持清晰分层。
- 左右侧栏均可切换详细模式：地区列表汇总职业与武器素材，职业列表展示可点击预览的宠物与武器。
- 独立宏弹窗按宠物和武器分页列出游戏命令，可一键复制召唤或道具检索宏。
- 地图标记、职业详情、宠物与武器预览、掉落地区之间双向导航。
- 职业完成状态保存在浏览器本地，并自动迁移旧版 `selectedData` 中的职业记录。
- 地图占满整个视口；桌面端使用“地区栏—地图—职业栏”三栏布局，移动端将地区与职业内容放进相互独立的模态弹窗。

## 本地开发

需要 Node.js 22.22.2+、24.15.0+ 或 26+ 与 npm。该范围与当前测试工具链的运行要求保持一致。

```bash
npm install
npm run dev
```

开发服务默认运行在 `http://127.0.0.1:8765/`。

```bash
npm run check      # 类型检查、测试、生产构建
npm run test       # 监听模式
npm run preview    # 预览生产构建
```

生产构建使用相对资源基路径，既可以部署在域名根目录，也可以部署在静态站点的子目录中。

## 结构

- `src/data`：职业、地区、地图坐标的唯一基础数据。
- `src/domain`：选择器、地图布局和进度迁移等纯业务逻辑。
- `src/components/map`：Leaflet 地图与工作台布局。
- `src/components/details`：职业、区域和大区详情。
- `src/styles`：按基础、地图、详情、工作台与地区导航拆分的样式模块。
- `public/assets/map/images`：9 张 1024×1024 的本地地图成品。
- `tests`：数据完整性、迁移与组件交互测试。

实施范围与决策见 [V2 路线](docs/v2-roadmap.md)，地图来源、缓存范围和再分发注意事项见 [地图素材说明](docs/map-assets.md)。

## 来源与许可

地图素材由 `scripts/extract-ffxiv-maps.ps1` 从本机《最终幻想 XIV》游戏客户端提取，将子地区高亮烘焙后发布为 1024×1024 JPEG；交互地图使用 [Leaflet](https://leafletjs.com/)，第三方软件许可见 [`public/THIRD_PARTY_NOTICES.txt`](public/THIRD_PARTY_NOTICES.txt)。
